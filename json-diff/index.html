About the JSON Diff Checker

Compare two JSON documents and find the structural differences between them, ignoring formatting and key order. The checker parses both inputs, prettifies and sorts keys, then highlights added, removed and changed values. It is ideal for comparing API responses between environments, reviewing configuration changes, validating migrations, or checking what a deployment altered in a settings file.

How to use the JSON Diff Checker

  1. Paste the first JSON document on the left.
  2. Paste the second JSON document on the right.
  3. Run the comparison.
  4. Review the highlighted differences line by line.

Frequently asked questions

Does key order matter?

No. Keys are sorted before comparison, so {"a":1,"b":2} and {"b":2,"a":1} are reported as identical.

What if one input is not valid JSON?

You will see a parse error indicating which side failed. Fix the syntax, for example a trailing comma, and run the comparison again.

Can I compare arrays?

Yes. Array elements are compared by position, so a reordered array shows as changed.
