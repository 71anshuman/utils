Base64 Converter

You can convert String to Base64 and vice versa

About the Base64 Converter

Base64 encodes binary data as plain ASCII text so it can travel safely through systems that only handle text, such as email, JSON, URLs and HTML. This converter encodes any text to Base64 and decodes Base64 strings back to readable text, which is handy for inspecting authentication headers, data URIs, JWT segments, configuration secrets and API payloads. It works entirely in your browser.

How to use the Base64 Converter

  1. Paste the text or Base64 string into the input box.
  2. Click Encode to produce Base64, or Decode to read an encoded string.
  3. Check the output for correctness.
  4. Copy the result with one click.

Frequently asked questions

Is Base64 encryption?

No. Base64 is an encoding, not encryption; anyone can decode it. Never rely on it to hide secrets.

Why is the encoded output longer than the input?

Base64 represents every 3 bytes as 4 characters, so output is about 33% larger, plus padding with = characters.

Does it support Unicode and emoji?

Yes. Text is converted to UTF-8 bytes before encoding, so any character is handled correctly.
