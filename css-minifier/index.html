About the CSS Minifier

Minifying CSS removes comments, whitespace and redundant characters so your stylesheet downloads faster without changing how it renders. This tool compresses CSS in one click and shows how many bytes you saved. It can also do the reverse: beautify minified CSS back into readable, indented rules when you need to inspect or edit a production stylesheet. Processing happens in your browser, so proprietary styles never leave your machine.

How to use the CSS Minifier

  1. Paste your CSS into the input panel.
  2. Click Minify to compress it, or Beautify to expand minified CSS.
  3. Check the size comparison to see the reduction.
  4. Copy the output or download it as a .css file.

Frequently asked questions

Will minification break my styles?

No. Only comments and unnecessary whitespace are removed; selectors, properties and values stay exactly the same.

How much smaller will my file get?

Typically 15–40%, depending on how much whitespace and commenting the original contains. Gzip on the server compresses it further.

Should I minify during build instead?

For production projects, yes; bundlers do this automatically. This tool is ideal for quick one-off tasks, snippets and legacy sites.
